# Solutions Engineer — POC Department

## My Core Role

**Client → Understand → Investigate → Design Solution → Coordinate R&D → Deliver → Validate**

I am the **technical bridge between the client and R&D/Engineering**.

### Responsibilities

- Understand the product 100%:
  - What it does
  - Features & functions
  - Architecture
  - Codebase
  - Deployment
  - Integrations
  - Limitations
- Explain the product based on the client's technical level.
- Attend client technical meetings.
- Understand client requirements, problems and expectations.
- Understand each client's infrastructure/environment.
- Troubleshoot and reproduce client problems.
- Find solutions/workarounds or coordinate solutions with R&D.
- Convert client problems into clear GitHub issues/tasks.
- Install/configure products and tools in client environments.
- Coordinate technical fixes, features and deployments with R&D.
- Validate solutions before/with the client.
- Manage technical deadlines and roadmap with Ferdous.
- Escalate unknown questions to R&D and return with accurate answers.

## 2. Architecture

Be able to understand and explain:

**Client Environment → Network → Servers → Services → Database → Search → External Services → Security → Deployment**

Questions I should naturally ask:

- Where does the data come from?
- Where does it go?
- Which service processes it?
- Where is it stored?
- What external dependencies exist?
- How is it deployed?
- How is it secured?
- What happens when something fails?

---

## 3. Client Communication

For technical questions:

**What we know → What needs verification → Next action → Owner → Expected update**

I do **not** need to guess an answer.

If uncertain:

**Client Question → Investigate → Ask R&D → Verify → Respond**
